SeventeenPHP 是一款超轻量 PHP7+ 框架，面向对象开发，小巧、优雅、高效，遵循 Apache2 开源协议发布的开源框架。SeventeenPHP 能够帮助开发者以最小的学习成本快速构建 Web 应用，在满足开发者最基础的分层开发、数据库和缓存访问等少量功能基础上，做到尽可能精简，以帮助您的应用基于框架高效运行。

核心特性：支持多应用、扩展机制、路由分发、自动加载、RESTFul Api、MVC 结构和依赖注入

文档地址：https://www.ourphp.net/SeventeenPHP/
